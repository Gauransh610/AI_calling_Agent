# neuraCall — React + Ollama AI Calling Agent

A full-stack, 100% free AI calling agent:

- **Frontend:** React (built with Vite) — landing page, real signup/login, and a dashboard
- **Backend:** Node.js (built-in `node:sqlite`, no backend npm dependencies)
- **Brain:** Your local Ollama model (`llama3.1:8b`) generates every reply
- **Voice:** Uses your browser's built-in Web Speech API for speech-to-text and text-to-speech — no paid APIs
- **Storage:** Every call (transcript, duration, status, summary) is saved to a local SQLite database

## One-time setup

```bash
# 1. Make sure Ollama has the model
ollama pull llama3.1:8b

# 2. Install and build the frontend (only needed once, or after you change frontend code)
cd frontend
npm install
npm run build
cd ..
```

This builds the React app into `public/`, which the Node server serves directly.

## Running it (every time)

Open **two terminal tabs**:

**Terminal 1 — make sure Ollama is running**
```bash
ollama serve
```
(if it's already running as a background service, this will just say the port is in use — that's fine)

**Terminal 2 — start the app**
```bash
npm start
```

Then open **http://localhost:4173** in Chrome (recommended — best Web Speech API support).

## How a call works

1. Log in → Dashboard → **Start new call**
2. Tap the mic and speak — your browser transcribes your voice
3. Your text is sent to the backend, which asks Ollama (`llama3.1:8b`) for a reply
4. The reply is spoken back to you using your browser's speech synthesis
5. Press **End call & save** — the full transcript, duration, and status are saved to the SQLite database
6. It immediately shows up in your dashboard's call history and stats

## API routes

- `GET /api/health`
- `POST /api/auth/signup`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/me`
- `GET /api/calls`
- `POST /api/calls`
- `GET /api/stats`
- `POST /api/agent/reply` — proxies to local Ollama (`http://127.0.0.1:11434`)

## Notes

- Everything runs 100% locally — no paid APIs, no cloud calls, no credit card.
- Speech recognition works best in Chrome/Edge. Safari has limited support; a text-input fallback is included in the call modal either way.
